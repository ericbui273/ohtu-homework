# Report of using AI for TDD work

Did the agent end up with a good implementation and high-quality tests?
In part A, did the agent stick to the minimal implementation, and did it leave the tests alone?
Did the agent at any point try to “cheat”, e.g. by hard-coding the value expected by the test?
Which division of work, A or B, felt better, and why?

The agent did end up with a good implementation and high-quality tests that match the requirements. In part A, it sticked to the minimal implementation and did not make any changes to the tests.

The agent also did not try to cheat by hard-coding the value expected. However, there are some repetitions in the code file and test file at the end, for which I asked it to do some refactoring.

It is hard to say which division of work felt better. Part B saved more time since I only needed to give the test requirements and the agent implemented both the test and the code for the test to pass for me. However, when I wrote the tests myself in part A, I felt like I could understand the test and code better.
